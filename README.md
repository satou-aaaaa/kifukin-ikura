# 寄附金控除いくら？（kifukin-ikura）

総所得金額等と1年に寄附した先・額（ふるさと納税・日本赤十字社・公益財団法人・認定NPO法人・政党・入学に関する寄附 など）の場面を読んで、寄附金控除の額を当てる1日5問の学習ゲーム。正解したら「どの決まり？」（寄附の額−2,000円・寄附を足す・所得の40％まで・2,000円以下・対象にならない寄附）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/kifukin-ikura/>

- 答えは、国税庁のタックスアンサーの計算式から出しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）（特定寄附金の合計か、総所得金額等の40％の低いほうから2,000円を引く。学校の入学に関する寄附・寄附をした人に特別の利益がおよぶ寄附は入らない）。
  - No.1150 一定の寄附金を支払ったとき（寄附金控除） <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1150.htm>
- 特定寄附金の先は国税庁の資料にあるものだけを使い、政党・認定NPO法人などは寄附金控除（所得控除）を選んだときだけ出します。税額・税額控除・住民税（ふるさと納税の住民税の控除）・申告の手続きは出しません。人と金額はつくりものです。
- このゲームは寄附金控除のしくみを知る練習です。税の相談の代わりではありません。実際の控除の額は、国税庁の資料や税務署で確かめてください。
